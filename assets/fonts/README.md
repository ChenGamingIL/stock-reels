# פונטים

`Heebo-Bold.ttf` — הפונט העברי של כל הכיסויים, הסטוריז והקרוסלות
(Heebo, פונט משתנה; `stockreels/render.py` בוחר ממנו את משקל Bold).

הקובץ שמור כאן בריפו **בכוונה**. עד נובמבר 2026 כל workflow שרינדר תמונות
הוריד אותו מ-GitHub בזמן הריצה, וכשההורדה נפלה כל הריצה נפלה איתה. הקובץ
שוקל ~120KB, אז אין סיבה להוריד אותו בכל ריצה.

**אל תוסיפו שלב `curl` שמוריד פונט ב-workflow חדש** — הקובץ כבר כאן אחרי
`actions/checkout`.

מקור: https://github.com/google/fonts/tree/main/ofl/heebo
רישיון: SIL Open Font License 1.1 — ראו `OFL.txt`. הרישיון מתיר הפצה מחדש
של הפונט, כולל בתוך ריפו, כל עוד הודעת הרישיון נשמרת לידו.
